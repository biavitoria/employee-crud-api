# Employee CRUD API

Uma aplicação full-stack simples para gerenciar funcionários (employees), construída para estudo.  
Front-end em **Vue.js**, backend em **Node.js / Express** e banco de dados **PostgreSQL**.

---

## 🔍 Visão Geral

Este projeto foi criado para praticar conceitos de APIs REST, integração entre front-end e back-end, e manipulação de dados em um banco relacional. Ele permite:

- Criar, ler, atualizar e deletar funcionários (CRUD)
- Exibir lista de funcionários no front-end
- Validar dados no back-end
- Estrutura básica de projeto para futuras extensões

---

## 🧱 Tecnologias Usadas

- **Frontend**: Vue.js, Vue Router, Axios  
- **Backend**: Node.js, Express  
- **Banco de Dados**: PostgreSQL  
- **Outros**: dotenv para variáveis de ambiente, scripts SQL para inicialização do banco
